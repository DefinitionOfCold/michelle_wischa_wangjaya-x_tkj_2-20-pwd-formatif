# Proyek Portofolio Web Dasar

Proyek portofolio web interaktif ini dikembangkan sebagai bagian dari pembelajaran Pemrograman Web Dasar di SMK Kristen Immanuel Pontianak.

## Struktur Folder Proyek

**index.html** : Halaman utama (beranda) yang berisi daftar link untuk membuka semua komponen dan halaman.

**components** : Kumpulan latihan pembuatan komponen web (seperti *button*, *card*, *navbar*, *sidebar*, dll).

**pages** : Berisi halaman-halaman web terpisah (seperti profil, tentang saya, kontak, galeri, dan hero section).

**styles** : Kumpulan file CSS untuk mendesain tampilan setiap halaman dan komponen.

**assets** : kumpulan gambar, font, video, dan icons.
